> **RoboCopy made easy.**  
> A friendly GUI for Windows' most reliable backup tool – no command-line memorizing required.

RobbyCopy wraps the built-in Windows `robocopy.exe` in a modern, beginner-friendly interface.
Seals always look the same… and so do your backups. 🦭
